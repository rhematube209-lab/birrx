SMS PERMISSIONS DECLARATION
Requested permissions: READ_SMS and RECEIVE_SMS.
Core-use exception requested: SMS-based money management.
Explanation to paste:
BirrX is a personal-finance and budgeting app for Ethiopian bank accounts and mobile wallets. With the user's permission it reads supported financial senders to import existing transactions, reported balances and mobile-package information, and receives new financial SMS to update records and notify users to categorize transactions. Parsing is on-device. It is not a default SMS app and does not send SMS or access contacts. Unmatched messages are reviewed. Manual and CSV import work without SMS permission. Optional AI analysis of eligible financial messages has a separate disclosure and affirmative consent, masks full account/phone numbers and removes links before transmission via Supabase to Gemini, and requires confirmation before saving results. SMS data is not used for advertising.

Supply an owner-recorded reviewer video link showing disclosure → grant permission → synthetic inbox import → new SMS and categorization → review inbox → AI consent → permission-denied manual alternative. Approval is Google's decision; do not submit without a demonstrable core SMS use case.
